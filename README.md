# Hibernate & JPA — Learning Examples

A focused set of Java examples for learning persistence with JPA/Hibernate.

## 📚 Covered Areas

- JPA CRUD operations
- Entity mapping
- Associations between entities
- Inheritance mapping
- JPA/Hibernate queries
- ORM fundamentals

## 🗂️ Examples

- `JpaCrud` — CRUD-oriented persistence example
- `JpaAssociation` — entity relationship mapping
- `JpaWithInheritance` — inheritance mapping
- `JPAQueries` — query examples

## 🎯 Purpose

The repository is a compact reference for understanding how Java objects are mapped to relational data through JPA/Hibernate.

## 🛠️ Stack

- Java
- JPA
- Hibernate
- Relational database concepts

> This is a learning/reference repository, not a production service.
